# useDialogs

> Promise-based `confirm`, `prompt` and `choose` (`if (!(await confirm("Delete?"))) return;`). Throws when no `DialogProvider` is mounted above.

- Import: `import { useDialogs } from "@sutra/ui/overlays"`
- Source: `packages/ui/src/primitives/confirm`

## Signature

```ts
useDialogs(): DialogsApi
```
