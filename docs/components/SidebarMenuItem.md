# SidebarMenuItem

> Wrapper for a menu button (and its sub menu).

- Import: `import { SidebarMenuItem } from "@sutra/ui"` (or from `@sutra/ui/navigation`)
- Source: `packages/ui/src/patterns/sidebar-navigation` (patterns)
- `data-slot`: `sidebar-menu-item`
- Part of [`SidebarMenu`](SidebarMenu.md)
- Also accepts the props of HTMLAttributes, LiHTMLAttributes

## Props

No props of its own.
