# CapabilityMonogram

> Monogram tile used when a capability has no icon. A `Monogram` preset (brand gradient, card radius).

- Import: `import { CapabilityMonogram } from "@cleanprompt/sutra-ui"` (or from `@cleanprompt/sutra-ui/agent-admin`)
- Source: `packages/ui/src/kits/agent-admin/capabilities` (kit `agent-admin`)
- `data-slot`: `capability-monogram`
- Also accepts the props of HTMLAttributes

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `name` (required) | `string` |  | Capability name; the monogram tile is derived from it. |
