# MediaBufferingIndicator

> Centered buffering spinner used by players.

- Import: `import { MediaBufferingIndicator } from "@cleanprompt/sutra-ui"` (or from `@cleanprompt/sutra-ui/media`)
- Source: `packages/ui/src/kits/media/media-controls-indicators` (kit `media`)
- Also accepts the props of HTMLAttributes

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | `"Buffering"` | Accessible label for the spinner. Default "Buffering". |
