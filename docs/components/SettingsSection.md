# SettingsSection

> A titled block of settings groups.

- Import: `import { SettingsSection } from "@sutra/ui"` (or from `@sutra/ui/identity`)
- Source: `packages/ui/src/patterns/settings` (patterns)
- Also accepts the props of HTMLAttributes

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `actions` | `React.ReactNode` |  | Right-aligned header content (e.g. a "Reset" button). |
| `description` | `React.ReactNode` |  | Supporting text under the heading. |
| `title` | `React.ReactNode` |  | Section heading. |
