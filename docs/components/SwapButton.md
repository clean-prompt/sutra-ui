# SwapButton

> Swap source/target languages with a half-turn animation.

- Import: `import { SwapButton } from "@cleanprompt/sutra-ui"` (or from `@cleanprompt/sutra-ui/voice`)
- Source: `packages/ui/src/kits/voice/translate-picker` (kit `voice`)
- Also accepts the props of HTMLAttributes, ButtonHTMLAttributes

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `onSwap` | `() => void` |  | Called when the user presses the button to swap source and target. |
